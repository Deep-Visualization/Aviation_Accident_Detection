About this project

This page is the interactive web version of my Aviation Accident Risk Prediction and Analysis System, built for CIS 550 – Advanced Machine Learning in the M.S. program at the University of Massachusetts Dartmouth. The original Python project (Flask app, Random Forest model with SMOTE, Streamlit and Power BI dashboards) is in this repository.

Data: NTSB Aviation Accident Database, cleaned (NTSB Cleaned dataset.xlsx). The page uses the 87,944 records from 1982 to 2022; seven earlier records are left out because those years have only one or two records each. build_data.py converts the spreadsheet into data/accidents.json for the browser.

Notes: about 92% of records are from the United States. Damage values with unusual spellings were merged (for example "substantial" into "Substantial"), and rare values are grouped as "Other / unknown".
