How it works

  1. Live weather. The page asks Open-Meteo for the current temperature, humidity, wind, visibility and conditions at the city. (The Flask app, app.py, used OpenWeatherMap, which needs a private API key that a public web page can't hide.)
  2. Weather risk score. Each factor adds points using the thresholds from model_utils.py, so the score is fully explained in the table.
  3. Flight rules. Visibility under 4,800 m (3 statute miles), fog or thunderstorms are treated as instrument-like conditions (IMC); otherwise visual (VMC).
  4. Historical context. Each aircraft type is matched to the closest engine group in the NTSB records, and the comparison chart shows how often accidents in that group were fatal in visual and instrument conditions.

For exploring the data only, not for real flight decisions. The trained Random Forest model (aircraft_damage_rf_model_smote.joblib) isn't included in the repository, so it isn't used here; app.py falls back to the same rule-based score when the model is missing.

About this project

The interactive web version of the Aviation Accident Risk Prediction and Analysis System, my Master's project for the M.S. in Computer and Information Science at the University of Massachusetts Dartmouth. The original Python project (Flask app, Random Forest model with SMOTE, Streamlit and Power BI dashboards) is in this repository.

Data: NTSB Aviation Accident Database, cleaned (NTSB Cleaned dataset.xlsx): 87,944 accidents from 1982 to 2022, about 92% in the United States. Build_data.py converts the spreadsheet into Accidents.json for this page.
